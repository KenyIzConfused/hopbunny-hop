# Plumberry Plains Vol. 1

Free Cute Animals for your cozy games. Fully rigged, socketed, and animated.  Base set of our Plumberry Plains animal villagers that give that "Animal Crossing" vibe.

**Game-ready and mobile-ready out of the box** — performance-optimized with every animation baked in. Import and play.

## What's included

- **26 animations per character** (26 everyday clips)
  - Everyday set: walk, run, sit, sit talk, interact, idle, talk, dance, pickup, jump, no, yes, pain, fall over, wave, cheer, crying, celebrate, axe chop, hammer, fish cast, fish reel, stick swing, paint, uppercut, shadow box
- **glTF (.glb)** — rigged + all animations embedded; imports natively into Godot, Unity (glTFast/UnityGLTF), Unreal, Blender, and three.js
- **FBX set** — base model plus one `character@clip.fbx` per animation (Unity's model@clip convention; Unreal-ready), textures embedded
- **OBJ + MTL + textures** — static rest pose for DCC work, renders, and printing pipelines
- **Concept art previews** for each character
- **README.md** (integration guide), **CONTENTS.md** (exact file listing), **TERMS.md** (license)

## Game-ready — desktop, web, and mobile

- Cozy chibi villager proportions (~0.95 m tall), optimized to run great everywhere — including mobile and web
- Fully rigged and animated with a crisp painted face; no rigging, retargeting, or texture work needed
- All animations are in-place (your controller drives movement) and ready to loop
- Built-in prop sockets (hands, head, back, chest) — attach hats, tools, and accessories and they follow every animation
- Full technical specs and integration notes are in the included README.md
